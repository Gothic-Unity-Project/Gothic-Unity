## Rules used

1. Structure, naming, namespaces, file locations, signatures, constants-vs-flags come from main.
2. Ours only as behavior main lacks or has wrong - ported into main's structure, no parallel versions.
3. Both did the same thing differently: main's, unless ours fixes a playtested bug (then a minimal delta, noted here).
4. Nothing removed silently - every conflicted file below.

## Flags removed (main made them always on or replaced them)

`EnableScreenMessages`, `EnableDialogAlwaysOnTop`, `EnableMenuZoom`, `EnableDialogFreeMovement` (duplicate),
`DialogMaxDistance` (now `Constants.DialogMaxDistance`).

## Kept from the branch on top of main (candidates for the next split)

- Seat fixes (Diego on the bench): `AnimationSystem` doesn't invert seated NPCs (`EnableMobSeatFix`), `UseMob` doesn't
  snap a seated NPC back to the slot, `IsAlreadySittingOnSameMob`, mob occupancy.
- `StatusBarAdapter` polling - several attribute writes on the branch still bypass `NpcService.SetAttribute`.
- `VRUiOnTop.CopyTo` for the hero's bars and the chapter screen.
- Mob dialog anchor, dialog range by body size, trade cancel on dialog end (in main's `DialogService`).
