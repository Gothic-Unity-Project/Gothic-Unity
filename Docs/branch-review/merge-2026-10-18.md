## Rules used

Same as [merge-2026-10-17](merge-2026-10-17.md): main's structure, naming, prefabs and flags win; ours only as behavior
main lacks, ported into main's structure; nothing removed silently.

## Flags removed (main made them always on or replaced them)

`MoverSpeedMultiplier` (main fixed the cm/ms unit, the multiplier only hid it), `EnableEngineMoverTiming` (main's mover
is the same: every keyframe, engine timing per segment), `EnableNoTurnWhileUsingMob`, `EnableMobSeatFix` (incl. the
2025 sit inversion - main removed `InvertYAxis`), `EnableDigSpots`, `DigSpotsRequireTool` (main: always the mob's own
tool), `EnableMobsiDialogs`, `EnableChildVobLoaders`.

## Kept from the branch on top of main (candidates for a split)

- Dig spots: only `B_SCGetTreasure` (`EnableDigSpotTreasureOnly`, now in `VmCacheService.IsDigSpot` - main's prefab
  choice uses it too), own renderers only in `VRDigSpot`; mob dialog anchor from the mob's own bounds
  (`EnableMobDialogOwnBounds`). Main's generic test still takes Mroczne Tajemnice's anvil and G2's Goldhacken/Stomp
  as dig spots - worth a PR.
- Movers: save state (`EnableLogicVobSaveState`), disabled movers (`EnableTriggerEnableState`), hit by projectiles,
  keyframes relative to the VOB, nested movers.
- Triggers: save state + activation counts, CodeMaster engine mode (`EnableEngineCodeMaster`), summed TriggerList
  delays, trigger zones/scripts hit by projectiles, green X on shootable targets, children of trigger zones next to
  them (not scaled).
- Mobs in `MobInteractionService`: fire toggle, crafting mobs taking their item into the hand (`EnableMobItemEvents`),
  required item for target mobs (`EnableMobRequiredItem`); VR: mummy loot, bookstand pages.
- Seated NPC keeps sitting when the AI queue is cleared (`NpcAiService.ClearAiQueue`), `UseMob` sets BS_SIT again.
