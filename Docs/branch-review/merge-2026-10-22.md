# Merge of main (PR #400 split/06-lighting, PR #401 split/07-bink) - 2026-10-22

Merged `origin/main` at `084e5e95` (32 commits: PR #400 lighting & day/night, PR #401 Bink videos in a VR cinema).

## Rules used

Same as [merge-2026-10-17](merge-2026-10-17.md): main's structure, naming, prefabs and flags win; ours only as behavior
main lacks, ported into main's structure; nothing removed silently. Unity YAML (prefab, project settings, developer
configs) only by taking one side of a conflict or through UnityMCP - no hand-written YAML.

## Flags removed (main made them always on or constants)

`EnableDayNightWorldLight`, `DayNightLightStrength` (night always uses Gothic's sky colors),
`EnableStaticLightsInLightMappedAreas`, `EnablePooledStationaryLights` (every world light is pooled),
`StaticLightPoolSize`, `StationaryLightPoolRefreshSeconds`, `StationaryLightMaxDistance` (constants),
`EnableScriptVideos` (`PlayVideo` always registered). The developer configs were reserialized by Unity to drop them.

## Kept from the branch on top of main (candidates for later slices)

- **Dynamic light slot** (torch in the hand, Light spell): main left it out for "slice 14/20" and described how to
  re-add it - slot 0 reserved (`DynamicLightIndex`, `UpdateDynamicLight`, `ClearDynamicLight`), the pool starts at
  slot 1. `StationaryLight` with its slot set before `Init()` lights its renderers itself (`Refresh()` follows the
  moving light), the pool never sees it.
- **World lightmaps** (`EnableWorldLightmaps`): lightmap pages in a texture array, per-pixel stationary lights in
  `Lit-World` (our shader is main's day/night via `normal.w` plus lightmaps), `IsBakedIntoWorld` lights, VOB world light
  (`EnableVobWorldLight`), RoomService sector cells in `WorldMeshBuilder` (main: slice 11).
- **Indoor darkness** (`EnableIndoorWorldDarkness`): main treats indoor worlds as always-day; with the flag they get
  a dim light, no sun, no fog (main's `_isIndoorWorld` detection is used).
- **Cinema**: "(Trigger) skip" label (`EnableCinemaSkipHint`), the spectator/monitor camera shows the cinema too,
  quit / back to the menu after the ending's videos (`EnableEndingReturnsToMenu`, now in `VRCinemaService`), VR stereo
  instancing in `GothicBinkYUV.shader` (only the left eye showed the video in single pass instanced).
- **Status bar**: our polling bar (hit numbers, HP/MAX text, save rebinding) plus main's "hidden in menus, while
  loading and during videos"; `HideHealthBar` still wins.
